📋 Daily Task Manager

A simple Daily Task Manager developed in C language.
This project allows users to add tasks, view tasks, and mark tasks as completed. The tasks are stored permanently in a text file.

• Features:-

-  Add a new task
-  View all tasks
-  Mark a task as completed
-  Store tasks in a file ("tasks.txt")
-  Tasks remain saved even after closing the program
-  Simple menu-driven interface

 • Technologies Used :-

- C Programming
- File Handling
- Structures
- Functions
- String Handling

• Project Structure:-

Daily-Task-Manager/
│
├── main.c
├── tasks.txt
└── README.md

«"tasks.txt" is created automatically when you add your first task.»

• How to Run:-

1. Clone the repository

git clone https://github.com/your-username/Daily-Task-Manager.git

2. Open the project folder

cd Daily-Task-Manager

3. Compile the program

Using GCC:

gcc main.c -o taskmanager

4. Run the program

Windows:

taskmanager.exe

Linux/macOS:

./taskmanager

 •How It Works:-

The program provides four options:

1. Add Task
2. View Tasks
3. Mark Task as Completed
4. Exit

Tasks are stored in the following format:

ID|Task|Status

For example:

1|Complete DSA Assignment|0
2|Study C Programming|1

Where:

- "0" = Pending
- "1" = Completed
